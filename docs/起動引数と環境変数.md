# 起動引数と環境変数

エンジン起動時に指定できる起動引数と環境変数の仕様をまとめています。  
各引数の概要は `uv run run.py --help` でも確認できます。起動引数や環境変数を変更した場合は、このドキュメントも更新してください。

## 優先順位

同じ設定を複数の方法で指定した場合、次の順に優先されます。

1. 起動引数
2. 環境変数
3. 設定ファイル（[設定ページ](http://127.0.0.1:50021/setting)で変更できる値）
4. デフォルト値

## 真偽値の環境変数

真偽値をとる環境変数（`VV_USE_GPU`・`VV_OUTPUT_LOG_UTF8`・`VV_DISABLE_MUTABLE_API`）は、`1` のとき有効、`0` または未設定のとき無効になります。  
それ以外の値を指定すると警告が出て、無効として扱われます。

## ユーザーディレクトリ

デフォルトのファイル保存先は、以下の `<user_data_dir>` 内の `voicevox-engine` ディレクトリです（Python で直接実行した場合は `voicevox-engine-dev`）。

- Windows: `C:\Users\<username>\AppData\Local\`
- macOS: `/Users/<username>/Library/Application Support/`
- Linux: `/home/<username>/.local/share/`

以下ではこのディレクトリを `<ユーザーディレクトリ>` と表記します。

## 接続

### ホスト

- 起動引数: `--host`
- 環境変数: `VV_HOST`
- デフォルト: `localhost`

接続を受け付けるホストアドレスです。  
デフォルトの `localhost` では IPv4 (`127.0.0.1`) と IPv6 (`::1`) の両方で接続を受け付けます。外部からの接続を受け付ける場合は `0.0.0.0` などを指定します。

### ポート番号

- 起動引数: `--port`
- 環境変数: `VV_PORT`
- デフォルト: `50021`

接続を受け付けるポート番号です。  
環境変数に 0 から 65535 の整数として解釈できない値を指定した場合は、警告が出て無視されます。

### プロキシの IP アドレス

- 環境変数: `FORWARDED_ALLOW_IPS`

リバースプロキシ等の背後でエンジンを動作させる場合に、プロキシの IP アドレスを指定します。  
指定すると、API が返す URL などがプロキシ経由のアクセスに合わせて正しく生成されます。Uvicorn が読み取る環境変数です。

## 音声ライブラリ

### VOICEVOX のディレクトリ

- 起動引数: `--voicevox_dir`

製品版 VOICEVOX もしくはコンパイル済みエンジンのディレクトリのパスです。  
指定したディレクトリから VOICEVOX CORE とそのランタイム、キャラクター情報を読み込みます。

### VOICEVOX CORE のディレクトリ

- 起動引数: `--voicelib_dir`（複数回指定可）

VOICEVOX CORE のディレクトリのパスです。  
`--voicevox_dir` と `--voicelib_dir` のどちらも指定しない場合は、エンジンのディレクトリから読み込みます。

### ランタイムのディレクトリ

- 起動引数: `--runtime_dir`（複数回指定可）

VOICEVOX CORE が使用するライブラリ（onnxruntime など）のディレクトリのパスです。  
システムの探索パス上にライブラリがある場合は指定不要です。

### モックで音声合成する

- 起動引数: `--enable_mock`

VOICEVOX CORE を使わず、モックで音声合成します。音声ライブラリがない環境での開発やテストに使います。

### GPU を使う

- 起動引数: `--use_gpu` / `--no-use_gpu`
- 環境変数: `VV_USE_GPU`
- デフォルト: 使わない

GPU を使って音声合成します。

### 全てのモデルを読み込む

- 起動引数: `--load_all_models`

起動時に全ての音声合成モデルを読み込みます。指定しない場合は、初めて使うときに読み込みます。

## 性能

### CPU スレッド数

- 起動引数: `--cpu_num_threads`
- 環境変数: `VV_CPU_NUM_THREADS`
- デフォルト: 論理コア数の半分（切り上げ）

音声合成を行うスレッド数です。`0` を指定した場合もデフォルト値になります。  
Windows と Linux では、性能の高い CPU コアを優先して使います。  
環境変数に整数として解釈できない値（空文字列を含む）を指定すると、エラー終了します。

### キャンセル可能な音声合成

- 起動引数: `--enable_cancellable_synthesis`

`/cancellable_synthesis` API を有効にします。実験的機能です。

### キャンセル可能な音声合成のプロセス数

- 起動引数: `--init_processes`
- デフォルト: `2`

`--enable_cancellable_synthesis` を指定した場合に、初期化時に生成するプロセス数です。

## CORS

### CORS の許可モード

- 起動引数: `--cors_policy_mode`
- 設定ファイル: `cors_policy_mode`
- デフォルト: `localapps`

`all` または `localapps` を指定できます。  
`all` は全てのオリジンからのリクエストを許可します。`localapps` は `app://.`・`localhost` 関連・ブラウザ拡張 URI に限定します。

### 許可するオリジン

- 起動引数: `--allow_origin`
- 設定ファイル: `allow_origin`

CORS の許可モードが `localapps` のときに、追加で許可するオリジンです。起動引数ではスペースで区切って複数指定できます。

### 設定ファイル

- 起動引数: `--setting_file`
- デフォルト: `<ユーザーディレクトリ>/setting.yml`

CORS の設定を保存する設定ファイルのパスです。設定ページで変更した値はこのファイルに保存されます。

## データ

### プリセットファイル

- 起動引数: `--preset_file`
- 環境変数: `VV_PRESET_FILE`
- デフォルト: `<ユーザーディレクトリ>/presets.yaml`

プリセット API で読み書きするプリセットファイルのパスです。

### データを変更する API を無効化する

- 起動引数: `--disable_mutable_api`
- 環境変数: `VV_DISABLE_MUTABLE_API`

辞書登録や設定変更など、エンジンの静的なデータを変更する API を無効化します。起動引数と環境変数のどちらかで指定すると無効化されます。

## ログ

### ログを UTF-8 で出力する

- 起動引数: `--output_log_utf8`
- 環境変数: `VV_OUTPUT_LOG_UTF8`

ログを UTF-8 で出力します。起動引数と環境変数のどちらでも指定しない場合は、環境によって自動的に決まります。
